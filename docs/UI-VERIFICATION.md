# Zitie 0.2.2 界面验证

验证使用实际 Prism 应用、实际视图模型和 Avalonia Headless + Skia。设置、文档、PDF 与受控下载放在隔离输出目录；更新安装使用测试服务，不执行真实安装。

最终产物使用共享控件与国际化包 `12.1.4.22`：正式发布程序 `--selfcheck`、原生 UI verifier 的 88 条断言、Windows Inno Setup 安装包编译及 SHA-256 生成均通过。README 静态截图来自该版本原生验证器。安装器未实际运行。

## 验证范围

- Core 与 Desktop 共 133 项测试。
- 实际窗口 88 条断言：326 个合并模板、真正的中文分词、八色 × 明暗模式、中英动态切换、五个参数页、内容与模板抽屉、文档保存恢复、PDF 导出、关于和完整更新状态。
- 标题栏使用八个配色点、Ursa 三态主题按钮和 Semi 语言菜单；无重复下拉。实际点击 Ursa 内部按钮验证浅色、深色、系统三态及偏好持久化，通过真实 ListBox 验证配色选择。
- 实际展开语言菜单并执行对应菜单项；Ursa 内部按钮的工具提示绑定宿主 T4 资源，在三态和中英切换时即时更新。
- 针对同一个已打开的编辑器切换语言，验证六类参数保持原值，并检查关闭状态下格型下拉框的 `SelectionBoxItem` 显示当前语言；选项使用稳定对象，避免替换字符串列表引发参数重置。
- 直接断言全局语言与保存的语言等于本次选择，避免选项刷新回写旧语言后产生测试假阳性；当前状态和字数摘要也随语言重算。
- 编辑器工具栏在 1240 和最小 1000 宽度下保持导出命令可见，文档命令在空间不足时可横向滚动；未保存状态用小圆点表达。
- 单文件复制到空目录后验收 90 个状态，包含两语 × 八色 × 明暗的模板库和编辑器、五参数页、内容选择、模板切换及受控更新。零外部资源请求、零 JavaScript 错误。
- 正式 `scripts/publish.ps1` Windows NativeAOT、发布程序 `--selfcheck`、实际原生 UI verifier。原生界面使用发布脚本生成的 `.zi` 模板包，验证发布布局中的资源读取。
- T4 生成结果、实际模板/内容快照与单文件内嵌产物均设 CI 检查。
- 图片资源以 Ordinal 固定顺序内嵌，并在中文和英文系统文化下分别检查，避免开发机与 CI 排序不同。
- 原型主窗和 About 显示桌面外边框、标题栏与标准窗口按钮，验证主窗最小化、还原及关闭后重开；About 的最小化、最大化与实际窗口一致禁用，禁用按钮不会改变布局。About 样例时间固定为 `2026-10-15 00:00:00`，生产程序继续显示真实构建时间。
- 八个色点来自共享主题固定色样，保留 Aurora 渐变，顺序与原生标题栏相同，不随明暗切换改变身份。

Jieba 的第三方模型加载使用默认反射 JSON。应用显式开启该能力，并由 `JiebaModelJsonContext` 为其嵌套字典预编译转换器；仅开启开关仍会在 NativeAOT 中失败。字帖文档和应用自有 JSON 继续使用源生成上下文，原生界面门禁实际验证“括号组词”能够拆成两个词。

Prism 原始依赖引入 Avalonia 11.0.7 的动态 XAML 加载器，和 Avalonia 12 的内部解析类型不匹配。中央依赖显式将这个传递包固定到 `12.1.4`，与应用的 Avalonia 主栈一致。

旧版 Prism 自带、应用未调用的 `DialogWindow` 模板仍报告 Avalonia 12 绑定扩展签名不匹配的 AOT 警告；应用未使用 Prism 的 `IDialogService`。保留完整反射元数据，不通过删除保留项压制警告。上述原生验证覆盖应用实际使用的窗口、对话框和更新流程，不代表第三方库全部未调用路径均已兼容。

## 对照约束

| 元素 | 原型与实现共用的尺寸或数据 |
| --- | --- |
| 主窗口 | 1240 × 840，标题栏 44，左导航 64 |
| 模板卡片 | 244 × 334，缩略图 226 高，卡片间隔 16，页面左右留白 26 |
| 编辑器 | 左参数区 316，五参数页，顶部命令栏与预览底栏独立 |
| 标题栏 | 八个 14 px 色点，24 px 选择区域；三态按钮与语言图标各 30 px；字号 12–30 |
| 目录 | 223 张样式示例图 + 103 张实际 ZitiePreview 缩略图，合并后 326 模板；内容 292 条 |
| 字体和主题 | 内置文楷同源子集、共享 StudioTheme 八色令牌；打印纸张保持独立配色 |

2026-10-15 对照中文、.NET 深色、1240 × 840 的实际原生图库，修正原型的导航与标题栏少 1 px、分类按钮间距和标题行高。两侧导航为 64 px、主标题 26 px、分类 12 px/30 px 高，分类折行为 12 + 6；首张 244 × 334 卡片均从窗口坐标 (91, 233) 开始。原型审计固定这些几何约束。编辑器同一内容页保留 316 px 参数区、13 px 正文、34 px 输入控件；内容样例和实际生成结果应分别比较，不将不同文本的纸张截图当作排版缺陷。

原型展示浏览器中的交互和标准格型预览；特殊题型排版、分页、系统文件选择、真实 PNG/PDF 导出及安装由桌面程序完成。图库中的全部缩略图来自真实示例或原生预览。字体栅格化、阴影和系统窗口装饰会因浏览器和系统不同而变化，不用主观百分比代替检查。

本机未进行普通桌面鼠标验收、真实安装，也未运行 Linux/macOS 安装器；对应架构的 NativeAOT 与安装包检查由原生 CI runner 执行，结果需要在发布后核对。

macOS ARM64 针对 Xcode 16.4 新链接器在完整 AOT 元数据的加数处理阶段崩溃，使用系统经典链接器，并显式关闭压缩调试段；运行时元数据保留策略不变。`v0.2.2` 五平台正式发布任务均已通过，包含该平台的 NativeAOT、自检和安装包生成。

发布资产检查发现 macOS 打包未附带 SHA-256 文件，原发布任务仍能成功。打包脚本现于公证装订后生成校验文件，工作流同时收集 DMG 与校验文件，并在创建 Release 前验证五个平台恰好十项资产、版本、非空文件和实际摘要。门禁测试覆盖完整产物、额外压缩包、篡改校验和缺失文件。`v0.2.2` 保留原标签和五个安装包，核对两个既有 DMG 的资产身份、字节数和 GitHub 服务端计算的 SHA-256 后，仅追加缺失的两份校验文件，再下载回读确认内容与文件摘要；不宣称已在本机完整下载并重新计算 DMG 摘要。
