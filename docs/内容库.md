# 字帖内容库

内置内容使用 Markdown 保存，应用通过 Markdig 语法树解析，不再使用 JSON 描述内容条目。

## 标题层级

- H1：学科或资源大类，例如“语文”“英语”“名言警句”
- H2：年级，例如“三年级”“五年级”“通用”
- H3：学期，例如“上册”“下册”“课外”
- H4：单元或专题
- H5：可选择的内容条目

H5 后的无序列表是元数据，支持“类型、教材、版本、朝代、作者、来源、版权”。普通段落是生成字帖时使用的正文。

## 内容边界

古诗、古文和传统名言等公共领域作品可以收录全文。现代语文课文和英语课文通常受版权保护，仓库只收录教材目录、基础字词和依据单元主题自编的练习句，不复制整篇教材正文。

家长持有合法教材内容时，可以按相同格式建立本地 Markdown 内容文件；是否允许再分发仍取决于原内容的授权。

## 教材版本

成都小学语文通常使用统编版。英语版本可能因学校和入学年份不同而变化，内置三年级内容按川教版 2024 秋、2025 春公开目录组织，五年级按当前公开的川教版目录组织。使用前应以孩子学校实际发放的教材为准。
