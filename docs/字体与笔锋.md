# 字体与笔锋

字帖中的起笔、行笔和收笔形态来自字体自身的字形轮廓。渲染器按字体轮廓直接绘制，不使用描边、锐化或局部拉伸来伪造笔锋，避免改变规范字形的笔画结构。

## 字体分类

- 规范楷体：笔画和间架结构更适合小学生临摹，默认优先。
- 书写体：具有自然书写感，可用于兴趣练习，但不等同于规范教材楷体。
- 印刷体：适合阅读和排版，不作为描红首选。
- 其他字体：无法仅凭字体名称可靠判断，界面标记为“笔锋未评估”。

内置霞鹜文楷按 SIL Open Font License 1.1 分发，是跨平台回退字体，分类为书写体。Windows 上存在楷体时会优先使用系统规范楷体。

## 限制

字体名称分类只能给出适用性提示，不能替代逐字审校。同一字体的不同版本可能存在字形差异。若后续内嵌新的规范楷体，必须先确认字体授权允许随应用再分发，并用小学常用字集做字形覆盖和笔画审校。
